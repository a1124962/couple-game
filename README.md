# 回声与骨

线上双人文字冒险，含合作战斗、心照不宣问答与实时共绘。

[开始游玩](https://a1124962.github.io/couple-game/)

## 当前发布版

本次发布的是已交付试玩的“旧港修灯塔”版。`index.html` 是完整可运行的单文件发布包，包含样式、游戏规则、剧情、PeerJS 和中文字体，可直接打开进行单人试玩，也可通过 GitHub Pages 创建联机房间。

[下载本版完整源码](./couple-game-updated.zip)。解压后从 `couple-game/index.html` 开始开发；拆分的源文件和第三方许可证均在压缩包中。后续修改源码时，需要重新生成单文件发布包或将解压后的目录完整部署。

原仓库 `data/` 中的长篇剧情及原版源文件仍予保留，不是当前单文件发布入口读取的文件。保留原世界观的长篇剧情交互改造另行进行。

## 联机

一人创建房间，另一人用邀请码或邀请链接加入。房主设备保存进度。使用 PeerJS 公共信令服务建立浏览器直连；部分受限网络可能无法建立连接。

## 验证

规则测试 12 项通过；已检查手机与桌面布局、单文件离线试玩、完整三幕流程。双端同步协议通过测试传输层验证，未据此宣称真实跨网络 WebRTC 已验证。

## 部署

GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。
