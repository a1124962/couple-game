## 内容与玩法

保留原骨城世界观和长篇主体：96 则事件、5 位人物的 15 次会面、213 个对话节点、9 个结局。清理 57 处成段重复，统一职业称谓，重写开场和关键因果衔接；修正玛拉船舱分支的生死矛盾、错误提前知道的线索、分离结局强行否定前面选择等问题。原稿 `data/events.js`、`data/npcs.js`、`data/endings.js` 完整保留供追溯，不直接载入。

每幕 16 站，共 48 站。主线与人物会面固定，途中选择支线、战斗、补给和成长。新增 9 段有独立文本的互动：3 次现场调查、3 次双方不同线索的解谜、3 次允许双方不同答案的组合事件；组合事件共 12 种结果。首领之前可对话，部分线索允许和解或改变结局。

五位 NPC 各有平静、温暖、伤感三种立绘表现，共 15 幅，按对话节点切换。桌面展示全身，手机展示上半身。静默者摘面具的表情只出现在对应揭示节点。

长文按场景分页，也可切换整段阅读。阅读进度各自掌握，共同选择需要双方同意。完整对话和选择进入手记，已发现的事件与结局可跨周目回读。支持中文大字号、键盘焦点、减少动态效果与 320px 起的窄屏。

另保留「心照不宣」10 题默契问答和实时共同画板。支持线上双人、单人辅助试玩、同一设备轮流操作。

## 运行与构建

源码目录内运行：

```sh
python3 -m http.server 8765
node tests/engine.test.cjs
node tools/build-standalone.cjs /path/to/index.html
```

无需编译依赖。构建脚本把活动脚本、立绘、中文字体与 PeerJS 客户端内嵌到一个 HTML；本地打开可单人玩，线上联机建议使用 HTTPS 网站。

文件说明：

- `engine.js`：确定性游戏规则、投票、战斗、成长与小游戏计分。
- `app.js`：房间、同步、输入、自动存档、手记和单人旅伴。
- `R.js`、`narrative-ui.js`、`style.css`：界面、分页、立绘表情与适配。
- `data/corpus.js`：由原长稿清理成段重复后的主体语料。
- `data/full-story.js`：清楚的三幕目标、关键场景、新互动与结局条件。
- `data/continuity.js`：旧稿分支连续性修正；与主体语料分离便于审阅。
- `data/rules-copy.js`：与规则一致的卡牌说明及零费/回能技能限制。
- `assets/characters/`：原始透明 PNG、人物表与生成提示词。
- `vendor/`：本地字体、PeerJS 客户端及许可证。
- `data/story.js`、`data/harbor-story.js`：此前旧港试玩版保留文件，本版不载入。

## 联机与存档

房主创建六位房间码，分享给旅伴。房主统一计算，访客发送操作；过时阶段的操作被拒绝，重复指令去重。答案在双方锁定前隐藏，重新连接使用原设备保存的房间凭证。

v3 使用独立的 `echoes-bones-v3` 存档和 `echoes-collection-v3` 收藏；此前试玩版存档不会被删除，也不会套入新主线。房主在原设备点「继续上次的旅程」恢复原房间，旅伴用原房间码重新加入。清除浏览器数据会清除本地进度。

客户端使用 PeerJS 公共信令服务，没有配置专用 TURN 中继。严格 NAT、企业网络等环境可能无法建立 WebRTC 连接；界面会提示重试或更换网络。双端协议测试不等于所有现实网络都能穿透。
